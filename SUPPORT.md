# Getting help

1. **Read the check message.** In your repository open **Actions**, click the latest run and read which task failed and why.
2. **Go back to the lesson.** Each task names the lesson that shows the method.
3. **Ask Helix**, the course tutor on lsma.co.uk.
4. **Still stuck?** Email **info@lsma.co.uk** with your course, the project name and a link to your repository. Your repository is private, so we can only see it if you are in our GitHub Classroom.

Please do not open public issues with your solution code in them.
